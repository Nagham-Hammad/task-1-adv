# task-1-adv
A simple Library Management System built with HTML, CSS, Typescript, Javascript 

## Project Overview
This project is a simple Library Management System built using HTML, CSS, TypeScript, and JavaScript. It allows user to view books, search for books, filter them by category, and change their availability status.

## Features
- Display a collection of books.
- Search for books by title or author.
- Filter books by category.
- Change a book's availability status.
- Use object-oriented programming concepts.
- Display reference books with additional information.

## Object-Oriented Programming Concepts
This project demonstrates the following OOP concepts:

- Classes and Objects: The project uses classes to represent books and the library.
- Inheritance: The ReferenceBook class extends the Book class.
- Encapsulation: Book properties and methods are organized within classes.
- Methods: Classes include methods for searching, filtering, and managing books.

## Technologies Used

## How to Run the Project

1. Download or clone the repository.
2. Make sure TypeScript is installed on your computer.
3. Open the project folder in your code editor.
4. Compile the TypeScript file:

   tsc book.ts
   
5. Open the project using a local development server, such as the Live Server extension in Visual Studio Code.
